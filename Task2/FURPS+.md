# Задание 2. FURPS+ таблица — Цифровизация депозитного направления бизнеса (MVP)

| Код    | Требования                                                                                                                 | Комментарий                                                                                                                                                                 |
|--------|----------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **F**  | **Функциональные (Functionality)**                                                                                         |                                                                                                                                                                             |
| F-1    | Перспективный клиент на сайте видит список доступных депозитов с актуальными ставками                                      | Требуется новый источник ставок: сейчас ставки ведутся только в XLS-файлах и нигде не публикуются. Публичный сайт должен получать актуальные данные без ручного копирования |
| F-2    | Подача заявки на сайте на депозит с указанием номера телефона и ФИО                                                        | Передаются персональные данные; нужна валидация и безопасная передача, шифрованием трафика (TLS/HTTPS)                                                                      |
| F-3    | Заявка с сайта попадает в систему кол-центра; менеджер кол-центра может предложить особые условия                          | Интеграция Сайт → Платформа кол-центра (подрядчик)                                                                                                                          |
| F-4    | Идентификация клиента лично в отделении (проверка документов)                                                              |                                                                                                                                                                             |
| F-5    | Зарегистрированный клиент видит список доступных депозитов с актуальными ставками и персонализированными ставками для себя | Персонализация ставок на основе профиля и истории клиента; отличается от публичного списка на сайте                                                                         |
| F-6    | Подача заявки в интернет-банк  на открытие депозита с указанием счёта и суммы                                              |                                                                                                                                                                             |
| F-7    | Операция подачи заявки в интернет-банке подтверждается СМС-кодом                                                           | СМС-функциональность реализуется силами команды банка, без доработок ядра системы подрядчиком                                                                               |
| F-8    | Менеджер бэк-офиса обрабатывает заявку: подтверждает условия депозита в АБС                                                |                                                                                                                                                                             |
| F-9    | Единый реестр ставок по депозитам, доступный бэк-офису депозитов и кредитов (вместо XLS-файлов)                            | Сейчас ставки не ведутся нигде, кроме XLS; работать с ними должны оба бэк-офиса. Источник истины для всех каналов                                                           |
| F-10   | Процесс согласования ставки по заявке реализуется в АБС (или в системе, связанной с АБС)                                   | Требуется наследовать существующий процесс согласования ставки в АБС                                                                                                        |
| **U**  | **Удобство использования (Usability)**                                                                                     |                                                                                                                                                                             |
| U-1    | Максимально удобный для клиента интерфейс подачи заявки на сайте и в интернет-банке                                        |                                                                                                                                                                             |
| U-2    | Соблюдение корпоративной системы дизайна: привычные цвета и брендированные элементы                                        |                                                                                                                                                                             |
| **R**  | **Надёжность (Reliability)**                                                                                               |                                                                                                                                                                             |
| R-1    | Доступность сервисов 24/7 на уровне не ниже 99,9% случаев                                                                  |                                                                                                                                                                             |
| R-2    | Исключить прямую работу интернет-банка с API АБС в новом процессе                                                          | Исключить прямую работу интернет-банка с API АБС в новом процессе                                                                                                           |
| R-3    | Сервисы интернет-банка выдерживают требуемую нагрузку                                                                      | Команда интернет-банка утверждает, что эти требования пока невыполнимы                                                                                                      |
| **P**  | **Производительность (Performance)**                                                                                       |                                                                                                                                                                             |
| P-1    | Отклик по всем операциям — миллисекунды (отображение депозитов, подача заявки, подтверждение)                              | Устранить проблему загрузки справочных данных дольше 1 секунды (наблюдается при платежах)                                                                                   |
| P-2    | Ёмкость на рост числа клиентов и онлайн-заявок без деградации                                                              | Предусмотреть равномерное горизонтальное масштабирование и распределение запросов между серверами, приложениями и ЦОД                                                       |
| **S**  | **Поддерживаемость (Supportability)**                                                                                      |                                                                                                                                                                             |
| S-1    | Максимально использовать существующие технологии банка (БД MS SQL и Oracle)                                                | Новые технологии должны быть совместимы с существующими платформами разработки                                                                                              |
| S-2    | Предпочтение технологиям, по которым в банке есть экспертиза (понимание хотя бы на уровне языка)                           |                                                                                                                                                                             |
| S-3    | Для очередей сообщений использовать Kafka                                                                                  | На перспективу                                                                                                                                                              |
| S-4    | Рассмотреть перевод интернет-банка на микросервисную архитектуру в рамках задачи открытия депозитов                        |                                                                                                                                                                             |
| S-5    | Разработать документацию для дальнейшего расширения системы                                                                |                                                                                                                                                                             |
| **+R** | **+ Ограничения (Restrictions)**                                                                                           |                                                                                                                                                                             |
| +R-1   | Заявку обрабатывает менеджер бэк-офиса вручную; автоматическое исполнение не реализуется                                   | Ограничение объёма MVP                                                                                                                                                      |
| +R-2   | Избегать доработок ядра системы подрядчиком (включая СМС)                                                                  |                                                                                                                                                                             |
| +R-3   | АБС масштабируется только вертикально (из-за своей БД)                                                                     |                                                                                                                                                                             |
